About this twin

Data source. The built-in run is a reduced-order replica written from your parameter file (Kt, limits, inertia, gear ratio, ramp, load profile, battery window). It is not the Simulink output.

Assumptions of the replica. Motor resistance 0.2 Ω, inductance 0.2 mH, back-EMF constant = Kt, converter efficiency 97 %, battery voltage linear in SOC, small friction, current limiter as a simple clamp.

Real data. Use Import CSV (columns Vbatt_V, Ibatt_A, SOC, RPM_rpm, Idc_f_A, Vdc_m_V, omega_wheel, Torque_Nm) or push_to_website.m from MATLAB. Pushed runs appear in Run history.

Checks. Same rules as RunAll step 9. FAIL opens a system-alert popup; WARN opens a warning popup.
