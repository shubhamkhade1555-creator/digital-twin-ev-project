About this twin

Model. A reduced-order replica written from BLDCSpeedControlData.m: back-EMF and current dynamics, speed PI, current limiter, battery OCV with resistance, projected temperatures, and a set of protection and sensor-check rules. It is an engineering estimate for trends and design review, not the Simulink output.

Known limit. The reduced model assumes a converter efficiency of 97 %. The reference RunAll runs show a Pdc/Pbatt ratio of about 1.05 to 1.11, which this model does not reproduce. Use the scenarios to compare cases with each other, not to predict absolute numbers.

Fault scenarios. Each scenario changes one or two physical quantities. The protection switch turns the prevention logic on or off, so the same fault can be seen as an incident or as a prevented event.

Real data. Use the server save, or push_to_website.m from MATLAB. Runs appear in Run history.
