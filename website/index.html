About this twin

Model. A reduced-order replica written from BLDCSpeedControlData.m. It is an engineering estimate for trends and design review, not the Simulink output.

Test cases. Each case names an engineering reference (IEC 60034-1, ISO 16750-2, ISO 26262, IEC 62660-1, UN ECE R100, SAE J1634). The case sets one or two conditions and states an expected outcome. The references show what the test is modelled on; they are not certification claims.

Known limit. The reduced model assumes a converter efficiency of 97 %. The RunAll reference runs show a Pdc/Pbatt ratio of about 0.92 to 1.11, which this model does not reproduce.

Simulation logs. Runs exported with export_to_website.m appear in the Simulation logs tab. Replay shows the recorded 1 ms data from the MATLAB run on the dashboard charts. Temperatures are not recorded by the Simulink model, so those curves stay empty during replay.
