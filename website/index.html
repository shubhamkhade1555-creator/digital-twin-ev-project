About this twin

Model. A reduced-order replica written from BLDCSpeedControlData.m. It is an engineering estimate for trends and design review, not the Simulink output.

Known limit. The reduced model assumes a converter efficiency of 97 %. The RunAll reference runs show a Pdc/Pbatt ratio of about 1.05 to 1.11, which this model does not reproduce. Use the scenarios and sweeps to compare cases with each other, not to predict absolute numbers.

Sweep. One parameter is changed in equal steps while everything else stays as set in the form and the scenario. Each step is a full run.

Real data. Runs pushed from MATLAB (push_to_website.m) appear in Run history.
